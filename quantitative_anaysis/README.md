# Quantitative Analysis

This directory contains applied analytics projects built on **SynthCity**, each designed around a real business or public policy question. Every case study uses synthetic observational data generated by the simulator to develop, evaluate, and communicate data-driven decisions in a controlled environment with known ground truth.

Each case study includes:

- 🐍 Reproducible Python scripts (`.py`)
- A written report summarizing the analysis, results, and key insights
- Publication-quality figures supporting the findings

Although the data are simulated, the analytical workflow mirrors real-world data science projects—from data preparation and exploratory analysis to modeling, evaluation, and communicating actionable recommendations.
